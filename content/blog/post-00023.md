## Documentation Vastly Extended

We are pleased to announce that the Strolch documentation has been vastly extended. We have added new sections, updated existing ones, and provided more examples to make it easier for you to understand and use Strolch.

As Strolch is a powerful and flexible framework, good documentation is essential for developers to leverage its full potential. We have been working hard to capture more details about the core concepts, APIs, and best practices.

### What's New?

- **Expanded Core Concepts**: More in-depth documentation on the Resource-Order-Activity model.
- **Detailed API Guides**: Improved documentation for Transactions, Searches, and Services.
- **Runtime & Configuration**: Clearer instructions on how to configure and run Strolch agents.
- **New Feature Documentation**: Documentation for recently added features like the new Notifications system and enhanced Security policies.
- **Best Practices**: Added a "Do and Don'ts" section to help you avoid common pitfalls.

We believe that these improvements will greatly benefit both new and experienced Strolch developers. We encourage you to explore the updated [documentation](/documentation) and let us know if you have any feedback.

Thank you for your continued support!

Happy coding!
